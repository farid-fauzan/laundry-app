# Laundry App

A microservices-based laundry management system.

## Tech Stack

| Layer | Technology |
|---|---|
| Language | Java 17 |
| Framework | Spring Boot 3.2 |
| Database | PostgreSQL 16 |
| Cache | Redis 7 + Spring Cache (`@Cacheable`, `@CacheEvict`, `@CachePut`) |
| Message Broker | Apache Kafka 3.6 |
| ORM | Spring Data JPA + Hibernate |
| API Docs | SpringDoc OpenAPI 2 (Swagger UI) |
| Containerization | Docker + Docker Compose |
| Architecture | Microservices (laundry-service, notification-service) |
| Build Tool | Maven |
